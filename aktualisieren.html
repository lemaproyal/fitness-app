Routine · dauert 5 Minuten

Fitness aktualisieren

Neue Fassung vom Rechner auf das Handy bringen. Der Ablauf ist jedes Mal derselbe.

Der Ablauf in Kurzform

  1. node werkzeuge/paket-bauen.js
  2. Bei GitHub den Inhalt von veroeffentlichen hochladen und Commit changes
  3. node werkzeuge/online-pruefen.js bis „Aktuell" erscheint
  4. Am Handy die App öffnen → Jetzt aktualisieren

Am Rechner

Rechner
  1. 01

    PowerShell im Projektordner öffnen

    Ordner FITNESS im Explorer öffnen, oben in die Adressleiste powershell tippen, Enter.

  2. 02

    Paket bauen

    node werkzeuge/paket-bauen.js

    Am Ende der Ausgabe steht die Versionsnummer. Merk sie dir — du brauchst sie in Schritt 05.

    17 Dateien, 128 KB gesamt
Service-Worker-Version: v6
    Wenn du selbst Dateien geändert hast: vorher in sw.js ganz oben const VERSION hochzählen. Ohne neue Nummer behält dein Handy den alten Stand — das ist der Fehler, der einen jedes Mal eine Viertelstunde kostet. Habe ich die Änderung gemacht, ist die Nummer schon hochgezählt.
  3. 03

    Hochladen

    github.com/lemaproyal/fitness-app öffnen → Add file → Upload files.

    Ordner FITNESS\veroeffentlichen im Explorer öffnen, Strg+A, alles ins Browserfenster ziehen.

    Den Inhalt ziehen, nicht den Ordner. Und danach bis ans Seitenende scrollen — der grüne Knopf Commit changes sitzt weit unter der Dateiliste. Ohne diesen Klick passiert nichts.
  4. 04

    Warten, bis GitHub fertig ist

    Rechts auf der Repository-Seite unter Deployments erscheint nach ein bis zwei Minuten ein frischer Eintrag github-pages mit grünem Haken.

  5. 05

    Nachprüfen, ob es online ist

    node werkzeuge/online-pruefen.js

    Solange dort noch die alte Nummer steht, baut GitHub noch — einfach nach einer Minute erneut ausführen.

    Lokal:    v6
Online:   v6

Aktuell. Am Handy die App öffnen und "Jetzt aktualisieren" antippen.

Am Handy

Handy
  1. 06

    App vom Startbildschirm öffnen

    Auf der Startseite erscheint Neue Fassung verfügbar mit einem Knopf Jetzt aktualisieren. Antippen — die App lädt sich selbst neu.

  2. 07

    Falls keine Meldung kommt

    App vollständig schließen: die Übersicht der zuletzt geöffneten Apps aufrufen und Fitness wegwischen. Dann erneut vom Startbildschirm starten.

    Der Service Worker prüft beim Start auf Neuerungen. Läuft die App schon länger im Hintergrund, hat sie noch nicht nachgesehen.

  3. 08

    Kurz gegenprüfen

    Sieht die Änderung so aus wie erwartet? Sind deine Übungen noch da?

    Deine Daten überstehen jedes Update. Übungen, Videolinks, Notizen und das Trainingsprotokoll liegen in der Datenbank des Handys — aktualisiert wird nur der Programmcode.

Wenn etwas klemmt

SymptomWas tun
online-pruefen zeigt dauerhaft die alte Nummer Der Commit fehlt. Bei GitHub auf Code schauen: Steht dort als Zeitpunkt der letzten Änderung etwas Aktuelles? Wenn nicht, Schritt 03 wiederholen und bis ans Seitenende scrollen.
Am Handy ändert sich nichts Meist wurde VERSION in sw.js nicht hochgezählt. Nummer erhöhen, Schritt 02 bis 05 wiederholen.
App startet gar nicht mehr Symbol vom Startbildschirm löschen, in Chrome lemaproyal.github.io/fitness-app/ öffnen, neu installieren. Die Datenbank bleibt dabei erhalten.
Übungen sind verschwunden Android hat den Speicher freigeräumt. Sicherung über ⋯ → Importieren einspielen und danach Dauerhaft speichern anfordern antippen.
Vor größeren Änderungen: in der App ⋯ → Exportieren und die JSON-Datei aufheben. Das ist deine einzige Sicherung.
